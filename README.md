# BPM Studio Pro

Маленькая программа: перетащил аудиофайлы (любой формат) — получил темп (BPM) и тональность.
При каждом новом запуске список пуст: результаты и кэш нигде не сохраняются.

## Где скачать

Вкладка **Releases** этого репозитория → последний релиз → файл `BPM-Studio-Pro-Setup-….exe` (Windows).
Версии для Mac (Intel и Apple Silicon) пока не собраны.

## Первый запуск на Windows

Установщик не подписан платным сертификатом, поэтому Windows может показать синее окно «Windows защитила ваш компьютер».
Нажмите **Подробнее → Выполнить в любом случае**.

## Как пользоваться

- Перетащите файлы или папки в окно, либо **Добавить…** внизу справа.
- Столбцы: файл, тональность, BPM. Если темп в треке плавает, рядом с числом стоит «~» (подробность в подсказке при наведении).
- Если определилось вдвое больше или меньше, чем нужно: выберите строку и нажмите `]` (×2) или `[` (÷2), либо правый клик по строке. `Backspace` — вернуть исходное значение.
- `Delete` убирает строки из списка (файлы не трогаются), `Ctrl+A` выбирает всё, `Ctrl+C` копирует.

## Для разработчика

```
npm install
npm test        # точность на синтетических треках, форматы, кириллица в путях, битый файл
npm start       # запуск окна
npm run dist    # установщик Windows в dist/
```

Сборка и выкладка установщика идут автоматически в GitHub Actions (`.github/workflows/build.yml`).

Технологии: Electron, ffmpeg-static (чтение любого формата), essentia.js (темп и тональность, WebAssembly).
Лицензия essentia.js — AGPL-3.0, программа для личного использования.
Анализируются первые 10 минут трека.
